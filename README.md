## Contacto

Formulario POST mediante FormSubmit dirigido a a.lopezerices@gmail.com, con validación nativa, honeypot y verificación del servicio. FormSubmit exige activar la dirección mediante un correo antes de entregar mensajes. No hay claves ni credenciales en el sitio. La entrega real de correo requiere esa activación y una prueba de recepción.
